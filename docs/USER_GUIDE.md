## Getting Started

### First Launch

When you first open BhriguWelt:

1. **Choose Your Experience**
   - Offline Mode: Pure calculations, no data transmission
   - Hybrid Mode: Local calculations + optional AI insights
   - Conversational Mode: Full AI assistant

2. **Set Up Security**
   - Create a 4-6 digit passcode
   - Enable biometric authentication (optional)
   - Your data is encrypted locally

3. **Create Your Profile**
   - Enter your name
   - Birth date and time (be as accurate as possible!)
   - Birth place (searchable location database)
   - Save securely to your device

### Understanding Birth Details

**Why Birth Time Matters:**
- Determines your Ascendant (Lagna)
- Calculates house positions
- Identifies current Dasha period
- Affects all predictions

**Tips for Accurate Birth Time:**
- Check birth certificate
- Ask parents/relatives
- Hospital records
- If unknown, rectification services available

## Privacy & Security

### 🔒 Data Encryption

**What's Encrypted:**
- All profiles
- All reports
- Birth details
- Personal notes
- Bookmarks
- Settings

**Encryption Method:**
- AES-GCM (military-grade)
- Key derived from your passcode
- Never stored in plain text
- Decrypt only with correct passcode

### 🔐 Passcode Protection

**Setting Up:**
1. First launch or Settings
2. Choose 4-6 digit code
3. Confirm passcode
4. Enable biometric (optional)
5. Set auto-lock timeout

**Security Tips:**
- Use unique passcode
- Don't share with others
- Enable auto-lock (5-15 minutes)
- Use biometric when available
- Change periodically

### 🌐 Offline-First Architecture

**Data Storage:**
- Everything stored on your device
- IndexedDB (encrypted)
- No cloud sync (by default)
- Works fully offline
- No internet required for core features

**When Data Leaves Your Device:**
- **Never** for offline mode
- **Optional** for AI features (hybrid/conversational)
- **Only birth data** sent to AI (never names)
- **Anonymized** using hashes
- **Deleted** after processing

### 🛡️ Privacy Modes

**Offline Mode:**
- Zero data transmission
- All calculations local

- Complete privacy

**Hybrid Mode:**
- Local calculations
- Optional AI insights
- Minimal data transmission

**Conversational Mode:**

### 🗑️ Data Deletion

**Options:**

**Secure Wipe:**

## Troubleshooting

### Common Issues

#### Can't Login / Forgot Passcode
**Problem:** Locked out of app
**Solutions:**
- Try common variations
- Check for auto-caps
- Look for saved passcode (secure notes)
- Last resort: Reset app (loses data)
- Always backup before reset!

#### Birth Chart Not Generating
**Problem:** Calculation fails
**Solutions:**
- Check birth details accuracy
- Verify location selected
- Try different time format
- Check internet (for location lookup)
- Clear cache and retry

#### AI Features Not Working
**Problem:** Can't generate AI predictions
**Solutions:**
- Check AI consent given
- Verify internet connection
- Switch to hybrid/conversational mode
- Check API quota (rate limits)
- Try again later
- Report issue if persists

#### Export/Import Fails
**Problem:** Can't export or import data
**Solutions:**
- Check storage space
- Try different format
- Verify passcode correct
- Check file not corrupted
- Use smaller data subset
- Contact support

#### Slow Performance
**Problem:** App is laggy
**Solutions:**
- Clear old data (>90 days)
- Clear analytics data
- Close other apps
- Restart device
- Update to latest version
- Reinstall app (backup first!)

### Error Messages

**"Encryption key mismatch"**
- Wrong passcode entered
- Corruption in encrypted data
- Try resetting encryption

**"Network error"**
- No internet connection
- Server maintenance
- Firewall blocking
- Try offline features

**"Invalid birth details"**
- Check date format
- Verify time is valid
- Ensure location selected
- Birth date can't be future

## FAQ

### General Questions

**Q: Is BhriguWelt free?**
A: Yes! Core features are completely free. Premium features (advanced AI) may require subscription in future.

**Q: Does it work offline?**
A: Yes! All core features work completely offline. Only AI features require internet.

**Q: Which platforms are supported?**
A: Web (all browsers), iOS (coming soon), Android (coming soon), Desktop (coming soon).

**Q: What's the difference from other astrology apps?**
A: Privacy-first, offline-capable, Vedic astrology focus, AI-enhanced insights, open-source.

### Privacy Questions

**Q: Do you sell my data?**
A: Never. We don't collect data to sell. Your data stays on your device.

**Q: Can you see my birth details?**
A: No. Everything is encrypted locally. We can't access your data.

**Q: What data do AI features send?**
A: Only birth data (date, time, place) - no names or identifying info. Anonymized with hashes.

**Q: Is my data secure?**
A: Yes. Military-grade AES-GCM encryption, local storage, passcode protection, optional biometric.

### Astrology Questions

**Q: How accurate are predictions?**
A: Vedic astrology offers guidance, not certainties. Accuracy depends on birth time accuracy and interpretation.

**Q: Why do I need exact birth time?**
A: It determines your Ascendant and house cusps, crucial for accurate predictions.

**Q: Can I change my karma?**
A: Yes! Astrology shows tendencies, not fixed fate. Free will and remedies can modify outcomes.

**Q: What if I don't know my birth time?**
A: You can still use Sun sign analysis. Consider professional birth time rectification.

**Q: Are AI predictions accurate?**
A: AI combines traditional wisdom with modern insights. Use as guidance along with traditional methods.

### Technical Questions

**Q: How much storage does the app use?**
A: ~50-100 MB initially, grows with data (profiles, reports). Plan for 200-500 MB max.

**Q: Can I use on multiple devices?**
A: Yes, but data doesn't auto-sync. Use export/import for manual sync.

**Q: What happens if I lose my device?**
A: If you've exported your data, import on new device. Otherwise, data is lost (it's never on our servers).

**Q: Is there a data backup?**
A: No automatic cloud backup (privacy). You must manually export for backup.

**Q: Can I delete my account?**
A: There's no account! Everything is local. Just uninstall app or use secure wipe.
