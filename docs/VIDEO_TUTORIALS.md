## 🎬 Production Guidelines

### Video Specifications

**Resolution:** 1920x1080 (Full HD)
**Frame Rate:** 30 fps
**Format:** MP4 (H.264)
**Audio:** AAC, 128 kbps stereo
**Duration:** 5-12 minutes per video
**Thumbnail:** 1280x720 (16:9 ratio)

### Recording Setup

1. **Screen Recording:**
   - Use OBS Studio or similar
   - Record at 1920x1080
   - Include system audio
   - Separate microphone track

2. **Audio Quality:**
   - Use quality microphone
   - Quiet recording environment
   - Normalize audio levels
   - Remove background noise

3. **Visual Quality:**
   - Clean desktop/background
   - Disable notifications during recording
   - Use cursor highlighting
   - Zoom in on important details

### Content Structure

Each video should follow this structure:

1. **Intro (15 seconds)**
   - Welcome message
   - Video topic
   - What viewers will learn

2. **Main Content (80%)**
   - Step-by-step demonstration
   - Clear explanations
   - Visual aids and annotations
   - Practical examples

3. **Key Takeaways (10%)**
   - Summary of main points
   - Tips and best practices
   - Common pitfalls to avoid

4. **Outro (15 seconds)**
   - Thank viewers
   - Next video preview
   - Call to action (like, subscribe, feedback)

### Voice-Over Script Template

```
[INTRO]
"Hello and welcome to BhriguWelt! In this tutorial, we'll explore [TOPIC].
By the end of this video, you'll be able to [LEARNING OUTCOME]."

[MAIN CONTENT]
"Let's get started. First, [STEP 1]..."
"Notice how [DETAIL]..."
"A helpful tip: [TIP]..."

[KEY TAKEAWAYS]
"To recap, we covered three main points:
1. [POINT 1]
2. [POINT 2]
3. [POINT 3]"

[OUTRO]
"Thanks for watching! In our next video, we'll cover [NEXT TOPIC].
If you found this helpful, please rate the app and share your feedback."
```

### Annotation Guidelines

- **Arrows:** Point to important UI elements
- **Circles:** Highlight clickable buttons
- **Boxes:** Emphasize input fields
- **Text Overlays:** Key concepts and definitions
- **Zoom Effects:** Focus on small details
- **Transitions:** Smooth cuts between sections

### Accessibility

- **Captions:** Add accurate closed captions
- **Transcripts:** Provide text versions
- **Clear Speech:** Speak clearly and at moderate pace
- **Visual Descriptions:** Describe visual elements for audio-only users
- **Keyboard Navigation:** Show keyboard shortcuts where applicable
