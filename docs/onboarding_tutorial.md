# Onboarding Tutorial

This tutorial helps new seekers move from first visit to their first set of readings in under five minutes.

1. **Start secure:** Load the site over HTTPS. If the site was opened via `http://`, the middleware automatically redirects to
   `https://` to protect birth details.
2. **Gather birth details:** Use the Horoscope form to capture name, birth date, birth time, and place. Inline validation
   highlights malformed fields before submission.
3. **Explore the foundation:** After submission, review the 12-house grid and focus labels. Tap a house to reveal the
   interpretation overlay and guidance cards.
4. **Continue to insights:** Use the progress rail to jump into Past Life, Future Timeline, or Matchmaking flows. Each step
   preserves the validated birth details, so users can explore without retyping.
5. **Download and share:** Export PDFs from the browser print dialog and send via encrypted channels (email or messaging apps
   that support end-to-end encryption).
6. **Stay in sync:** Enable notifications to receive weekly updates. All notifications reference the HTTPS backend endpoint
   configured in `NEXT_PUBLIC_BACKEND_URL`.

For facilitators, pair this tutorial with `docs/contributor_tutorial.md` to test every flow using staging data.
