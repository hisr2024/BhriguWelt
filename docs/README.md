## 📱 Soul Journey Mobile App

### Interpretation Engine
The core of the Soul Journey app - generates deterministic, explainable Soul Journey reports.

- **[Design Document](./interpretation_engine_design.md)** - Complete specification with schemas, pseudocode, and examples
- **[Architecture Document](./interpretation_engine_architecture.md)** - Visual diagrams and system architecture
- **[Quick Reference](./interpretation_engine_quick_reference.md)** - Quick start guide and API reference
- **[JSON Schemas](./interpretation_engine_schemas.json)** - Formal schema definitions

**Key Features:**
- Deterministic (same input → same output)
- Explainable (traceable to source)
- Ethical (neutral language, privacy-first)
- Offline-first (no external dependencies)

## 📖 Documentation Standards

### Writing Guidelines
- Use clear, concise language
- Include code examples where applicable
- Add diagrams for complex systems
- Keep examples up-to-date with implementation

### Document Structure
```markdown
# Title

## Overview
Brief description

## Prerequisites
What you need to know/have

## Content Sections
Main documentation

## Examples
Practical examples

## References
Links and resources
```

### Updating Documentation
1. Make changes to relevant .md files
2. Update this index if adding new documents
3. Ensure cross-references are correct
4. Test code examples
5. Commit with descriptive message
